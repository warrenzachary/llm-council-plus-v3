# ConsiliumAI — Getting Started

## Step 1: Install the app

1. Open the file Warren sent you: **ConsiliumAI_Setup.exe**
2. If Windows shows a warning ("Windows protected your PC"), click **More info** → **Run anyway**
3. Click through the installer: **Next → Next → Install → Finish**
4. When asked about **public and private network access**, click **Allow access** — the app needs this to connect to the AI services

> **Note:** If the installer says the folder already exists, click **Yes** to continue — this is normal if you've installed before.

---

## Step 2: Add your API key

The app opens automatically when the installer finishes. If it doesn't, double-click **ConsiliumAI** on your Desktop.

1. Wait about 10 seconds for your browser to open
2. Click the **Settings** icon in the top right corner
3. Go to **LLM API Keys**
4. Enter the API key Warren sent you
5. Click **Test**, then **Save Changes**

---

## Step 3: Use it daily

Double-click **ConsiliumAI** on your Desktop whenever you want to use it.

---

## Troubleshooting

**"This site can't be reached" in the browser** — The app is still starting up. Wait 20 seconds and refresh, or go to `http://localhost:8001` manually.

**The browser doesn't open at all** — Double-click the ConsiliumAI shortcut on your Desktop to try again.

**Something else went wrong** — Contact Warren.
